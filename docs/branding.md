# Optimus brand mark

`public/optimus-logo.png` is the shared transparent PNG mark used in the sidebar,
login page and browser favicon. The interlocking blue and cyan O represents
coordinated infrastructure. Keep the same mark across these surfaces.

Generated with the built-in image generation tool on 2026-09-17 (no CLI/API
fallback). Final prompt:

> Use case: logo-brand. Create a single production-ready square logo icon for
> Optimus, a Kubernetes and infrastructure management console. A bold geometric
> O built from interlocking blue and cyan segments, conveying coordinated
> infrastructure. Flat crisp vector-like silhouette, no lettering, no wordmark,
> no shadows, no mockup, no fine detail. Centered symbol filling 85% of canvas,
> genuinely transparent background, strong contrast on both dark navy and white
> surfaces. Must remain recognizable as a tiny browser favicon. Save the
> generated asset for use in the project.
