# v0.1.0 Release Preparation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development. Track implementation and separate specification/quality reviews below.

**Goal:** Prepare the first MIT-licensed Optimus release with user-facing documentation, tested Linux amd64/arm64 artifacts, versioned images and a reviewable GitHub Release draft.

**Architecture:** Preserve the existing main-image CI. Add a tag-only release workflow that validates exact-main CI, tests native release images and extracted archive binaries, and publishes those same image bytes to both registries before assembling a draft. Keep schema 19 unchanged.

**Tech stack:** Go 1.25, Bun 1.3, Python standard library, Bash, Docker/Buildx, PostgreSQL 17 and GitHub Actions/CLI.

**Current status (2026-11-06):** [v0.1.0 is published](https://github.com/ArkGravity/optimus/releases/tag/v0.1.0) after explicit operator approval of the verified draft. The chronological preparation checkpoints below remain unchanged; final publication evidence is appended at the end. No Production rollout or database recreation was performed.
