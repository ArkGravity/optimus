## Product scope

v0.1.4 contains main since verified v0.1.3: Docker hosts/images/containers over
SSH (migration 00021, probe-before-save) and Inventory UX polish (Provider-first
accounts, Native ID-only VPC detail, shared Back, filter Reset). The operator
reported Production acceptance of this revision before release authorization.
Existing head20 databases upgrade in place through 00021, then `optimus seed`
refreshes Docker menu grants. Custom roles need an explicit write grant for
Docker mutations.

Downloaded verification archives live under ignored `tmp/v014-verification/`
and may be removed after the checks. No further application database operation
was performed by this release task.
